# Quested Website

A single-page static website for **Quested — Fantasy Quest Journal**. It includes authentic Home and New Quest Editor screenshots, Support and Privacy sections, and is intended for GitHub Pages. The site has not been published.

## Local preview

From the repository root (`/Users/bg/Desktop/Questedwebsite`), run:

```sh
python3 -m http.server 8000 --directory docs
```

Then open <http://localhost:8000>.

## Website files

- `docs/index.html` — page content, Support and Privacy anchors.
- `docs/styles/site.css` — responsive styling.
- `docs/assets/images/quested-home-screenshot.jpg` — authentic Home screenshot.
- `docs/assets/images/quested-editor-screenshot.jpg` — authentic New Quest Editor screenshot.
- `docs/assets/images/finalbackground.jpg` — optimized landscape artwork.
- `docs/assets/images/` — app mark, favicon, and Apple touch icon.
- `docs/assets/fonts/Mork Dungeon Mac.ttf` — font distributed under SIL Open Font License 1.1; see `docs/assets/fonts/OFL.txt`.

The site uses static HTML and CSS without JavaScript, analytics, advertising, a backend, or build dependencies. GitHub Pages is the intended host; the public repository and site URL have not been confirmed.
